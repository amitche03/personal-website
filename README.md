# Mitchell Anderson — Personal Website

A simple, fast personal website and portfolio for Mitchell Anderson.

## Stack
- **Framework**: Next.js (App Router), React, TypeScript
- **Styling**: Tailwind CSS
- **Hosting**: Vercel

## Pages
- **Home**: Hero, highlights
- **About**: Bio, campus involvement, teaching, skills
- **Projects**: Featured work and case studies
- **Resume**: Embedded PDF
- **Interests**: Web/Data/A11y/ML topics with curated links
- **Contact**: Icon cards for GitHub, LinkedIn, and copy‑to‑clipboard email

## Local Development
```bash
npm install
npm run dev
# open http://localhost:3000
```

## Deploy
Deploy with Vercel by connecting this repo. The default settings work out of the box for Next.js.
